# Дашборд СПК

Производственный дашборд цехов ПВХ и Алюминий (план/факт, НЗП, отчёт ДД, недельный отчёт, двери/окна по бригадам, Excel «выработка на человека»).

- `dashboard.html` — вся страница одним файлом (версия 101), публикуется как Artifact в Claude; данные хранятся в базе артефакта.
- `CLAUDE.md` — инструкция для ассистента и договорённости; `dashboard-status.md` — правила расчёта и схема базы.
- `db/` — выгрузка базы на 09.11.2026 (`sample-data/` — её копия).
- `source-files/` — исходные файлы 1С и Excel (см. `source-files/README.md`).

Библиотеки (SheetJS, html2canvas, jsPDF, ExcelJS) подгружаются с cdnjs. Репозиторий закрытый: в нём реальные данные производства.
