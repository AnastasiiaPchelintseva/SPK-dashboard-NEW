# Дашборд СПК

Производственный дашборд цехов ПВХ и Алюминий (план/факт, НЗП, недельный отчёт, двери/окна по бригадам).

- `dashboard.html` — вся страница одним файлом (версия 89), публикуется как Artifact в Claude; данные хранятся в базе артефакта.
- `CLAUDE.md` — правила расчётов и структура данных.

Библиотеки (SheetJS, html2canvas, jsPDF) подгружаются с cdnjs.
