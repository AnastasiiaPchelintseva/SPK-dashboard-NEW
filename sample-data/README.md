# Пример данных (для разработки и проверки)

Выгрузка документов базы дашборда: `state/main`, `brk/` (смены), `nzp/`+`nzd/` (НЗП на 28.10.2026 и справочники), `wk/` (снимки отклонения), `rsu/`, `msd/`.
Структура — в `dashboard-status.md`, раздел «Данные в базе».

Обезличено: фамилии бригадиров и мастеров, названия объектов и изделий в НЗП, номера заказов. Объёмы (м², шт., план/факт) реальные — перед передачей третьим лицам проверьте, можно ли их раскрывать.
