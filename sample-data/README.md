# Выгрузка базы дашборда (09.11.2026, версия приложения 101)

Полный срез коллекций `state`, `brk`, `nzp`, `nzd`, `wk`, `rsu`, `msd` из claude.use("db"): по файлу на документ, `<коллекция>/<id>.json`. Структура — в `dashboard-status.md`, раздел «Данные в базе».
Данные не обезличены (репозиторий закрытый). Не открывайте доступ третьим лицам без проверки.
`sample-data/` — копия этого же среза для разработки и проверки.
